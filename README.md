# Suryoday Solar Shine

Build a premium solar company website for Suryoday Solar Energy using Vite React, React Router DOM, Tailwind CSS, Framer Motion and React Icons.

The website should have the same premium feel, smooth animations, section flow, conversion focus and professional layout as modern solar industry websites, while using the Suryoday Solar Energy logo colors and branding. Solar websites typically emphasize lead forms, trust indicators, project showcases, savings calculators, testimonials and strong call-to-actions.
